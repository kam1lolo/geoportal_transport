# Geoportal — Transport kolejowy w Warszawie

Interaktywna mapa webowa przedstawiająca zasięg transportu kolejowego w Warszawie.
Zrealizowana z użyciem biblioteki Leaflet.js.

## Warstwy

- Linie i stacje kolejowe (PKP)
- Linia metra M1 i M2
- Linia WKD
- Granice Warszawy
- Izochrony dostępności (wtyczka Leaflet.Reachability + OpenRouteService API)

## Uruchomienie

Wystarczy otworzyć plik `index.html` w przeglądarce.
